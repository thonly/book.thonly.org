# book.thonly.org

The library of books by Thon Ly, starting with *Two Singularities* (a new edition each 7 January from 2027).
Free to read; thanks welcomed; printed copies sold at cost; no advertising.

- **The record behind each edition** — the rules committed before each run, the transcripts and the ledger — is at
  [github.com/thonly/two-singularities](https://github.com/thonly/two-singularities).
